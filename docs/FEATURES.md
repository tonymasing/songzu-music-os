# 功能與工具需求

| 功能 | 分享版 | 其他條件 |
| --- | --- | --- |
| 賽博龐克 UI、作品庫、靈感及偏好筆記 | 已包含 | 使用自己的資料 |
| 音樂播放器、循環、速度及調性 | 已包含 | 可播放的本機音檔 |
| DAW 與原生音訊服務 | 已包含 | 錄音需麥克風權限及可用裝置 |
| 備份、缺檔檢查、儲存設定 | 已包含 | 備份目的地有足夠容量 |
| 轉檔、部分音訊檢查與輸出 | 程式已包含 | FFmpeg / ffprobe 需另行安裝 |
| 進階音高、和弦、分軌與模型分析 | 接口與腳本已包含 | 對應 Python 環境、模型與外部工具；依引擎狀態配置 |
| GarageBand 交接 | 接口已包含 | 自己安裝 GarageBand 和相容 operator，設定路徑 |
| Connect / 手機連線 | 桌面服務與手機頁面已包含 | 配對；遠端通道需自行設定及安裝相應工具 |
| 手機 APK / iOS App | 本次未附安裝包 | 手機來源介面不等於已完成手機發行 |
| 音色取樣庫 | 選用匯入工具 | 取樣不隨包提供；來源及授權見各匯入工具 |

進階引擎未配置時不可視為分析完成。自動測試能驗證程式啟動、介面及合成音檔播放，無法代替不同音訊介面的錄音品質與延遲測試。

AI 建議供創作參考；輸出、備份與發行請依工作台顯示的實際狀態操作。
