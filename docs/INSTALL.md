# 安裝與日常使用

## 適用版本

本次提供 Apple Silicon（M 系列）Mac 的 DMG。Intel Mac、Windows 和手機原生安裝包尚未在本次發行中驗證。

## 安裝

[開啟 GitHub 下載頁](https://github.com/tonymasing/songzu-music-os/releases/tag/v0.32.17.001)。目前已公開下載，不需要 GitHub 帳號或邀請。

1. 從本專案 Releases 下載 `Songzu-Music-OS-0.32.17-arm64.dmg`。
2. 打開 DMG，把「頌祖音樂 OS」拖到「應用程式」。
3. 從「應用程式」開啟 App，等待本機服務啟動，從選單進入 DAW 或作品庫。

這是尚未經 Apple 公證的分享包。macOS 可能要求在「系統設定 → 隱私權與安全性」確認允許開啟；不要關閉整台電腦的安全防護。詳見 [Apple 開啟 App 說明](https://support.apple.com/en-us/102445)。麥克風權限在需要錄音時授予。

不需手動開背景預覽。App 內的本機服務是軟體執行的一部分，退出 App 後服務可能關閉；瀏覽器單獨開 `127.0.0.1` 不能取代啟動 App。

## 第一次開啟

預設資料夾為「文件 / Songzu Music OS Data」，包含：

| 目錄 | 用途 |
| --- | --- |
| `prisma/dev.db` | 作品與設定資料庫 |
| `uploads/` | 匯入檔案與錄音 |
| `exports/` | 輸出成果 |
| `backups/` | 備份 |
| `music-db/00_INBOX/` | 自己加入的參考音樂 |
| `music-db/_metadata/song_notes/` | 音樂偏好筆記 |
| `.cache/` | 可重新產生的分析快取 |

作品資料庫從空白開始；「音樂資料庫 → 參考資料庫」已附兩首 Call of Silence MP3 與完整卡片，可直接播放。也可以匯入自己的音樂。可在「資料維護」管理備份與儲存位置。

## 更新

退出 App，先透過資料維護建立備份，再安裝新版。App 與個人資料分開存放；不要刪除自己的資料夾。空白資料結構只在資料庫不存在時建立，不會覆蓋已存在的作品。升級到 0.32.17 後，首次進入參考資料庫會自動加入兩首隨附歌曲，不需要重設資料。

## 常見問題

- **127.0.0.1 拒絕連線**：先打開「應用程式」裡的頌祖音樂 OS，等待啟動完成。單靠重新整理舊瀏覽器頁不會啟動服務。
- **看不到朋友的歌曲**：此版只附 City Pop、Reggae / Rocksteady 兩首 Call of Silence。請確認安裝 0.32.17 並進入參考資料庫；其他歌曲須自行匯入。
- **部分分析或轉檔顯示尚未安裝**：見[功能與工具需求](FEATURES.md)。播放器和作品管理不需要先裝全部 AI 模型。
- **無法錄音**：檢查 macOS 麥克風權限、音訊介面及輸入裝置；本次自動驗證不取代實體麥克風測試。
- **無法啟動**：App 選單可開啟本機 log。回報系統版本、晶片種類、App 版本和錯誤文字；不要上傳自己的資料庫、金鑰或完整錄音。
